# Deneme sayfası

Bu sayfa düzeni denemek içindir. Sol menü, ortada içerik ve sağda "Bu sayfada" listesi görünmeli. Türkçe karakterler: ç ğ ı İ ö ş ü, Ç Ğ I İ Ö Ş Ü.

## Metin ve listeler

Bir paragrafın satırları yaklaşık 65 karakterde kırılır, böylece geniş ekranda da rahat okunur. Ekranın genişliğini metin değil, kenar çubukları doldurur. Bu cümle satır uzunluğunu görmek için biraz uzun tutuldu.

- Haftada en az iki makale oku
- Bilmediğin kavramları **not et**
- Kaynaklarını [Zotero](https://www.zotero.org) ile düzenli tut

1. Başlığı ve özeti oku
2. Şekillere ve sonuca bak
3. Sonra ayrıntıya in

### Alıntı ve kod

> Bu sayfalar resmî metinlerin sadeleştirilmiş anlatımıdır. Bağlayıcı olan resmî metinlerdir.

Satır içi kod: `npm run build`. Kod bloğu:

```bash
npm install
npm run dev
```

### Geniş tablo

Geniş tablolar metin sütununu aşabilir. Mobilde yatay kaydırılır.

| Süre veya sayı | Değer     | Açıklama                                                                    | Kaynak        |
| -------------- | --------- | --------------------------------------------------------------------------- | ------------- |
| Örnek süre     | 4 yarıyıl | Bu satır yalnızca tablo düzenini denemek içindir, gerçek bir kural değildir | Örnek md. 1/1 |
| Örnek kredi    | 21 kredi  | Uzun açıklamalar hücre içinde alt satıra geçer                              | Örnek md. 2   |
| Örnek oran     | %20       | Kaynak sütunu en sağda durur                                                | Örnek s. 3    |
